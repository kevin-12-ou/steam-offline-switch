# 实现原理

本文说明 Steam 离线开关是怎么工作的、为什么这样设计、以及它的边界。

## 1. 为什么「离线」能同时玩家庭共享游戏

Steam 家庭共享的授权判定是：**某个账号「在线」并启动了某款共享游戏时，这份授权就归它占用**，其他家庭成员无法同时在线玩同一款。

当你让自己的 Steam **处于离线状态**后，Steam 客户端不再向 Steam 服务器实时校验「这份共享授权当前是否被占用」，于是：

- 好友在他那边（在线）照常玩；
- 你这边（离线）也能启动并游玩同一款游戏。

因此**关键不是断网，而是「让 Steam 认为自己离线」**。本工具通过阻断 `steam.exe` 的出站网络，让客户端进入离线行为，从而达成这个效果。具体能否同时玩、以及是否属于合规使用，取决于 Steam 家庭组规则与用户协议（见 README 免责声明）。

## 2. 为什么是「防火墙规则」而不是别的办法

可选方案对比：

| 方案 | 问题 |
| --- | --- |
| 拔网线 / 关 Wi-Fi | 断掉整台机器，本地服务、下载、远程桌面全废 |
| 退出 Steam 用「离线模式」登录 | 需要重启 Steam、重新登录，操作繁琐且易误操作 |
| 改 hosts / 代理 | 容易影响其他程序，且 Steam 有多个域名/端口，难覆盖全 |
| **Windows 防火墙按程序拦截** | **只针对 `steam.exe`，其他程序零影响；可即时启停；系统原生、无需注入** |

本工具选第 4 种：**按「程序路径」拦截出站连接**，这是 Windows 防火墙原生支持的能力。

## 3. 具体做法

### 3.1 建立规则

首次运行 / 点「重建规则」时，通过 COM 接口 `HNetCfg.FwPolicy2`（`HNetCfg.FwRule`）为 `steam.exe` 创建 **6 条出站「阻止」规则**，名称固定为 `SteamOfflineSwitch_0` ~ `SteamOfflineSwitch_5`。

每条规则的属性：

| 属性 | 值 | 含义 |
| --- | --- | --- |
| `Direction` | `2` (OUT) | 出站 |
| `Action` | `0` (BLOCK) | 阻止 |
| `Protocol` | `256` (ANY) | 所有协议 |
| `Profiles` | `0x7FFFFFFF` | 域/专用/公用全部配置文件 |
| `ApplicationName` | `steam.exe` 的完整路径 | 只作用于该程序 |

> **为什么是 6 条？** Windows 防火墙对「同名规则」的启停与匹配在不同系统版本上偶有差异；用多条同参数规则可以提高命中率与稳定性，也便于批量启停时确认每一条都生效。它们完全等价，只是冗余。

### 3.2 开关 = 改 `Enabled`

「在线 / 离线」不做任何规则的增删，只是把这些规则的 `Enabled` 属性设为 `false` / `true`：

- 离线：6 条规则 `Enabled = true` → `steam.exe` 出站被阻断；
- 在线：6 条规则 `Enabled = false` → 放行。

因为规则本身一直存在，所以：切换**即时生效**、**无需重启 Steam**、**退出本工具后状态依然保持**（重启电脑后规则也还在，只是保持上次的启用状态）。

### 3.3 为什么只拦 `steam.exe`，不拦 `SteamService.exe`

- `steam.exe` 是 Steam 客户端主进程，它的联网被断，客户端就表现为「离线」。
- `SteamService.exe` 是底层服务（负责更新、部分后台能力）。如果把它也拦掉，容易出现更新异常、服务报错等问题，反而降低稳定性。
- 因此**规则只针对 `steam.exe`**，尽量把副作用降到最低。

### 3.4 权限：为什么需要管理员

修改防火墙规则（添加/启停）需要管理员权限。程序通过清单声明 `requireAdministrator`，启动时会：

1. 检测当前是否已是管理员；
2. 若不是，用 `runas` 以管理员身份重新启动自己，然后原进程退出。

如果你的 UAC 设置为「不提示直接提升」（`ConsentPromptBehaviorAdmin=0`），这一步会**静默完成**、不弹 UAC 框；否则会弹一次 UAC 确认。

## 4. 其他设计点

- **单实例 + 唤回窗口**：用命名互斥量保证只运行一个实例；同时监听一个命名管道。再次双击 exe 时，新进程连上管道通知旧实例「把窗口显示出来」，随后自己退出。这样即使旧窗口被收进托盘，也不会「双击无反应」。
- **DPI 感知**：清单声明 DPI 感知，界面用 `AutoScaleMode.Dpi`，在 150% 等缩放下不会出现按钮换行/裁切。
- **配置与日志**：设置存于 `%LOCALAPPDATA%\SteamOfflineSwitch\settings.ini`，日志 `app.log`。程序不联网、不上传数据。
- **命令行**：`--cli status|offline|online|ensure`，结果写到 `cli-result.txt`，方便脚本调用。
- **托盘**：`NotifyIcon` 提供快捷菜单；图标按在线/离线动态切换。

## 5. 已知边界

- **只对「按程序路径」的 TCP/UDP 出站生效**。若 Steam 未来改用其他进程联网，需要相应调整目标进程。
- **仅影响本机该路径的程序**。Steam 装在别处时，需用「选择路径…」指定正确的 `steam.exe`。
- **家庭共享合规性**：本工具不改变 Steam 的共享策略，能否同时玩取决于 Steam 规则；请遵守用户协议。
- **离线无云存档**：这是 Steam 离线模式的固有行为，使用时需注意存档同步（见 README 重要提醒）。
