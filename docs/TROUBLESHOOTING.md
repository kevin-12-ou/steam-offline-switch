# 常见问题与排障

## 启动 / 打开

### 双击没反应、打不开？

1. 本工具是**单实例**的。若之前把它最小化到了托盘（或点 × 时按设置收进了托盘），它**并没有退出**，只是藏在右下角通知区。
   - **再双击一次 exe** 即会把窗口唤回前台；
   - 或直接双击右下角托盘区的图标。
2. 若连托盘图标也找不到：打开「任务管理器」→ 结束 `SteamOfflineSwitch.exe` → 重新双击 exe。
3. 若启动时报错弹窗，请查看 `%LOCALAPPDATA%\SteamOfflineSwitch\app.log` 末尾的 `[ERROR]`。

### 提示需要管理员权限？

管理 Windows 防火墙必须有管理员权限。程序会尝试自动提权：

- UAC 若为「不提示直接提升」，会静默完成；
- 否则会弹 UAC，请点「是」；
- 如果被取消/阻止：右键 exe →「以管理员身份运行」。

### SmartScreen 提示「未知发布者 / 已保护你的电脑」？

exe 未做代码签名，首次运行可能出现。点「更多信息 → 仍要运行」。不放心可自行编译（见 README「从源码编译」）。

### 杀毒软件误报？

程序会以管理员身份修改防火墙规则，部分安全软件可能敏感。本程序：不联网、不上传数据、不装服务/驱动、不注入进程，只操作名称前缀为 `SteamOfflineSwitch_` 的防火墙规则。可加入信任，或自行编译。

## 切换 / 生效

### 切到「离线」了，但 Steam 还能联网 / 好友还是不能玩？

- **确认路径**：界面「Steam 程序」必须是**正在运行**的那个 `steam.exe`。Steam 可能装在别的盘（如 `D:\...`），用「选择路径…」指定后点「重建规则」。
- **给点时间**：切换瞬间 Steam 可能仍维持已建立的连接。等几秒，或**重启一次 Steam 客户端**让它进入离线模式。
- **确认状态**：可运行 `SteamOfflineSwitch.exe --cli status`，返回 `BLOCKED` 表示规则已生效。

### 切回「在线」后仍连不上？

- 运行 `--cli online` 或界面切回「在线」，返回 `OPEN` 即已放行。
- 若仍异常，检查 Windows 防火墙里是否残留旧规则：托盘 →「删除全部规则」，再重新「重建规则」。

### 同时只能一个人玩的规则没变？

本工具只负责让**你的 Steam 离线**；能否与好友同时玩取决于 **Steam 家庭组规则**与游戏本身。请确认：对方在线、你在离线、且游戏支持家庭共享。

## 存档

### 存档会不会丢 / 冲突？

Steam 离线期间**不会上传云存档**。若好友此时也在用同一存档位，可能冲突。建议：

1. 离线前，在游戏「属性 → 通用」里**关闭「Steam 云」**；
2. 玩完切回「在线」，再重新开启「Steam 云」并等待同步完成；
3. 确认同步完成后再退出 Steam。

## 卸载 / 还原

### 我想彻底移除

1. 托盘右键 →「删除全部防火墙规则…」（或运行 `--cli online` 只放行、不删除）；
2. 删除程序文件夹；
3. 如勾选过「开机自启」，可在界面取消勾选，或手动删除注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `SteamOfflineSwitch` 值。

### 防火墙里怎么手动确认规则

`Win + R` → 输入 `wf.msc` →「出站规则」，查找名称以 `SteamOfflineSwitch_` 开头的规则。

## 日志与反馈

- 日志：`%LOCALAPPDATA%\SteamOfflineSwitch\app.log`（界面左下「打开日志文件夹」）。
- 提 Issue 时请附：Windows 版本、程序版本、复现步骤、日志相关片段（勿贴敏感信息）。
